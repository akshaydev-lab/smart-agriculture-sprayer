# 🌱 Smart Agriculture Sprayer

A working agricultural spraying prototype built using DC motors, a water pump, and manually wired push-button controls.

## Project Overview

The Smart Agriculture Sprayer was developed to explore a practical approach to agricultural spraying using a motorized pump system.

The electrical connections were designed and assembled manually without using a ready-made controller.

## Features

- Two 12V DC motors in the setup.
- 24V water pump for spraying.
- Two push buttons for front-side and back-side spraying control.
- Manually assembled electrical connections.
- Working prototype.
